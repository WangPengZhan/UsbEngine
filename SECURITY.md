# Security policy

[简体中文](SECURITY.zh-CN.md)

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting for this repository when it is available. If private reporting is unavailable, contact the repository maintainer through the GitHub profile and include a way to reproduce the issue securely.

Please include the affected version or commit, the operating system, the impact, and reproduction steps. Avoid publishing exploit details before the issue has been assessed and a fix is available.

## Supported versions

There are no published release branches with a separate support policy yet. The maintainer will assess reports against the current default branch.
